# Motor conversacional S0–S11

## Regra central

Uma resposta só autoriza o avanço sustentado pelas evidências que contém. Fluxo: mensagem → evidências → fatos/inferências → intenção → estado → informação faltante → decisão → próxima melhor ação → tarefa/registro.

## Decisões

- permanecer: obter evidência ainda ausente;
- avançar: há sinal suficiente para a próxima etapa;
- retroceder: dado novo invalida classificação anterior;
- pausar: timing inadequado, sem recusa;
- redirecionar: novo interlocutor;
- encerrar: recusa inequívoca, opt-out ou regra aplicável.

## Estados

| Estado | Evidência mínima | Objetivo |
|---|---|---|
| S0 Sem contexto | nenhuma informação concreta | obter primeira informação útil |
| S1 Contexto inicial | resposta informativa | entender situação atual |
| S2 Ponto A | processo/problema atual concreto | especificar problema e impacto |
| S3 Ponto B | resultado futuro expresso | compreender meta e relevância |
| S4 Lacuna A→B | A e B explícitos | explorar obstáculo, impacto e prioridade |
| S5 Engajamento qualificado | aceita aprofundar/receber valor | entregar valor e testar disposição |
| S6 Interesse em próximo passo | deseja explorar solução | propor ação concreta de baixo atrito |
| S7 Agendamento | aceita conversar, horário pendente | fechar data e remover obstáculo |
| S8 Reunião marcada | data confirmada | preparar e aumentar comparecimento |
| S9 Silêncio temporário | ausência sem recusa | reengajar apenas com nova relevância |
| S10 Pausa | timing/evento futuro | suspender e retomar no combinado |
| S11 Parada | recusa/opt-out | encerrar e aplicar política adequada |

## Saída obrigatória

Para cada resposta: diagnóstico; evidências literais; inferências; intenção; estado; decisão; objetivo; informação faltante; mensagem sugerida; condição de avanço; condição de parada; atualização/tarefa Apollo.

## Regras especiais

- Dor explícita permite aprofundar, não saltar automaticamente para reunião.
- “Interessante” é curiosidade vaga.
- Pergunta de preço é intenção comercial não qualificada; responda com faixa aprovada quando existir.
- Fornecedor atual pede escopo/satisfação, sem ataque.
- Indicação exige fonte e autorização para citar.
- “Sem tempo” é pausa; “não quero receber” é supressão.
- Toda resposta humana pausa a automação até triagem.
