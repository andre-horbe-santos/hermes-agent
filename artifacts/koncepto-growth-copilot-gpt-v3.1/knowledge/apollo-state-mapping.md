# Mapeamento operacional no Apollo

Apollo é a fonte oficial. Antes de propor campos novos, inventarie campos, estágios, listas e regras existentes; estenda o que existe e não duplique sem aprovação.

## Dados mínimos

| Grupo | Dados |
|---|---|
| Estado | estado S0–S11, decisão, data e origem |
| Evidência | trecho literal, fato, inferência e lacuna |
| Descoberta | ponto A, ponto B, lacuna, problema, impacto, prioridade |
| Resposta | intenção, objeção, informação faltante, próxima melhor ação |
| Operação | proprietário, tarefa, vencimento, sequência e último contato |
| Retomada | motivo, data/evento, contexto que deve ser revalidado |
| Indicação | contato anterior, novo contato, fonte e autorização para citar |
| Parada | motivo, opt-out/supressão, canal e data |

## Política de escrita

1. Ler schema/campos disponíveis.
2. Mostrar mapeamento campo lógico → campo Apollo.
3. Marcar o que não possui destino.
4. Apresentar prévia do lote.
5. Obter aprovação conforme `approval-matrix.md`.
6. Escrever somente o aprovado.
7. Ler amostra e verificar.

Se não houver ferramenta MCP para salvar pesquisa, campo ou lista, entregue filtros e passos manuais. Não alegue sucesso sem ID, URL ou leitura posterior.
